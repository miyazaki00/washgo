# Wash Go! LP

公開用のWash Go!ランディングページです。外部サービス専用のバンドルを使わず、一般的なHTML・CSS・JavaScriptで作成しています。

## ファイル

- `index.html`：文章とページ構成
- `styles.css`：色・余白・スマートフォン表示などのデザイン
- `script.js`：スマートフォンメニューと表示アニメーション
- `assets/`：今後、ロゴや正式に利用許諾を得た画像を置く場所

## パソコンで確認する

`index.html` をブラウザで開くだけでも確認できます。ローカルサーバーを使う場合は、このフォルダで次を実行します。

```sh
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 想定ドメイン

`washgo.jp`（取得先はお名前.com / ムームードメイン / Cloudflare など。Netlify・Vercelとは別契約）

## 公開手順

初心者向けの詳細手順は [`PUBLISH.md`](./PUBLISH.md) を見てください。

要約すると次の流れです。

1. GitHub にコードを置く
2. Netlify でサイト公開（仮URL発行）
3. `washgo.jp` を取得
4. ドメインを Netlify に接続

## 公開前に必ず決める項目

1. ドメイン取得とDNS接続（予定: washgo.jp）
2. 問い合わせ先または問い合わせフォーム
3. 予約サービスと予約先URL
4. 正式な店舗情報
5. 正式な料金・メニュー
6. 運営会社情報とプライバシーポリシー
7. ロゴ、SNS共有画像、必要に応じて商用利用可能な写真

現在、未確定情報は「準備中」と表示しています。
